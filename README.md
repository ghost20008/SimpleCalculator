# Simple Python CLI Calculator

A simple, interactive command-line calculator built with Python. This project is part of my coding journey as I build my foundation in Python programming and core Object-Oriented Programming (OOP) principles.

## Features

- **Basic Operations:** Addition, Subtraction, Multiplication, and Division.
- **Object-Oriented Design:** Encapsulates math operations inside a `Calculator` class.
- **Error Handling:** Safe division checks (prevents division by zero) and input validation for non-numeric entries.
- **Interactive Menu:** Continuous terminal loop allowing users to perform multiple calculations.
